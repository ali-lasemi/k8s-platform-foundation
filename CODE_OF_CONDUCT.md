# Code of Conduct

## Our standards

Project participants are expected to:

- communicate respectfully and professionally
- provide constructive technical feedback
- focus criticism on implementations, not individuals
- document decisions and assumptions
- protect private and security-sensitive information
- accept responsibility for mistakes and corrections

Unacceptable behavior includes:

- harassment or discrimination
- personal attacks
- deliberate disruption
- publishing private information
- abusive or threatening communication
- knowingly introducing malicious changes

## Enforcement

Instances of unacceptable behavior may be reported privately to the repository
maintainer.

The maintainer may edit or remove contributions, comments, issues or other
content that violates this code of conduct. Repeated or serious violations may
result in temporary or permanent exclusion from the project.

## Scope

This code applies to project spaces and public interactions representing the
project.
