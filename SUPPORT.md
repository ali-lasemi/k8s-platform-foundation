# Support

## Support channels

Use GitHub Issues for:

- reproducible bugs
- feature proposals
- documentation defects
- operational improvements

Use GitHub Discussions when enabled for:

- implementation questions
- architecture discussions
- usage guidance

Security vulnerabilities must follow `SECURITY.md` and must not be reported in
public issues.

## Before opening an issue

Confirm that:

- the problem is reproducible
- the latest `main` branch was tested
- existing issues were searched
- relevant logs were collected
- secrets were removed from all output
- the expected and actual behavior are clearly described

## Support boundaries

This project does not provide:

- emergency production support
- managed cluster administration
- recovery guarantees
- support for undocumented local modifications
- support for exposed or compromised credentials

Infrastructure-specific values such as IP address pools, DNS zones and storage
configuration must be adapted and validated by the operator.
