# Changelog

All notable changes to this project are documented in this file.

The project follows Semantic Versioning.

## [1.0.0] - 2026-08-08

### Added

- Reproducible and version-pinned k3s bootstrap.
- Control-plane and worker lifecycle automation.
- Flux-based GitOps reconciliation.
- Traefik ingress and MetalLB integration.
- Automated TLS with cert-manager and Let's Encrypt.
- ExternalDNS integration for Cloudflare.
- SOPS and Age encrypted GitOps secrets management.
- Kyverno security policy enforcement.
- Comprehensive positive and negative policy regression tests.
- Prometheus, Grafana, Loki and Grafana Alloy observability stack.
- Platform alerting and Prometheus recording rules.
- etcd snapshot automation and checksum verification.
- Velero Kubernetes resource and volume backup integration.
- Disaster recovery workflows and validation.
- Flagger progressive delivery with canary and blue-green patterns.
- Prometheus-based rollout analysis and automated rollback.
- Development, staging and production Kustomize environments.
- Git-based environment promotion and rollback procedures.
- Production resource quotas and disruption safeguards.
- Version-controlled Mermaid architecture diagrams.
- Production incident response and failure recovery runbooks.
- Repository governance, contribution and security policies.
- CI quality gates for YAML, Markdown, shell, Kubernetes and security checks.
- Production readiness and release-gate validation.
